# Time-Calculator

A basic program to add/subtract times

Its a basic program that calculates times so it can find the result of adding and subtracting 2 or more times in the format HH:MM:SS

The [Time_calculator_GUI](Time_calculator_GUI.c) file in the repo includes a GUI version of this using GTK4
-Need GTK4 for compiling and running this file
-Currently only works with keyboard(No numbers in the GUI)
